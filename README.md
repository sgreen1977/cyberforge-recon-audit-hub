## Overview

CyberForge consolidates critical security utilities into a unified Python architecture aimed at network auditors, ethical hackers, and security analysts. Instead of coordinating disparate standalone programs, operators can perform complete technical assessments within one framework.

Whether your immediate goal involves probing network perimeters, auditing web application endpoints, or performing cryptographic checks, CyberForge streamlined modules deliver rapid visibility. Cross-platform support ensures seamless operation across Windows, Mac, and Linux workstations.

## Core Capabilities

- Network scanning engine to discover live assets and available services
- Port auditor to pinpoint open entry points across target infrastructure
- WHOIS query client to retrieve administrative and domain ownership details
- DNS intelligence collector to harvest records and host relationships
- Subdomain discovery tool to map out expanded attack surfaces
- Cryptographic suite offering hash calculation and cracking functions
- Credential analyzer to measure password complexity and policy strength
- Web stack profiler for identifying remote frameworks and software components
- SQL injection auditing helpers for web app vulnerability assessments
- SSL/TLS security inspector to validate certificates and transport configurations

## Operation

Launch CyberForge via command line and activate the module required for your operational phase.

Recommended steps:
1. Fire up the application environment
2. Choose your desired reconnaissance, scanning, or evaluation utility
3. Supply the target host, domain, or data file at the prompt
4. Examine findings and transition to the next assessment step

Execution pattern:

    python main.py

From the main menu, load specific components to execute host discovery, port verification, sub-domain gathering, tech stack identification, or TLS configuration checks.

## Customization

System settings can be updated directly inside the local configuration files provided within the Python project structure.

Config example:

    settings = {
      "timeout": 10,
      "target": "example.com",
      "output_dir": "./output"
    }

Modify execution timeouts, target defaults, and export locations to match your environment specifications.
